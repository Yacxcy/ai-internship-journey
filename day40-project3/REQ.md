# Project 3: 面试 Coach（AI 模拟面试官）

## 一句话定位
面向求职者的 AI 模拟面试教练——根据简历自动生成针对性面试题，实时追问深挖，最终输出多维度评分与改进建议，解决"面试练习缺反馈、刷题无针对性"的痛点。

## 用户画像
- 主要用户：校招/社招求职者（应届生、1-5 年经验转岗/跳槽者）
- 次要用户：HR 或猎头顾问（用于候选人预筛选）、培训机构讲师（用于学员模拟考核）
- 痛点：
  1. 海量八股文无从下手，不知道哪些知识点是自己的薄弱环节
  2. 自己练习面试缺乏真实压力感和即时追问，回答深度无法评估
  3. 缺乏量化的面试表现评估，不知道具体该从哪些维度改进

## 核心功能
1. **简历解析与问题生成** - 上传 PDF/文本简历，Agent 自动提取技术栈、项目经历、工作年限等关键信息，从知识库（技术八股 + 行为面经）中匹配并生成个性化面试问题列表
2. **多轮模拟面试与追问** - 支持"技术面"和"行为面"两种模式，Agent 扮演面试官角色，根据用户回答内容实时追问、深挖细节，模拟真实面试的压力与节奏
3. **智能评分与反馈报告** - 面试结束后，从多个维度（技术深度、表达清晰度、项目经验匹配度、行为回答 STAR 结构完整度等）给出评分，并输出逐题点评和改进建议

## 边界（不做的）
- 不做实时语音对话（V1 仅支持文本输入输出）
- 不做视频/表情分析
- 不做简历的自动修改与美化（那是简历工具的职责）
- 不保证面试通过（仅提供模拟练习，不预测真实面试结果）
- 不做多语言面试官角色扮演（V1 仅支持中文面试官 + 中英文问答）

## 非功能性要求
- 响应时间 < 5s（问题生成 / 追问延迟）
- 单次对话 token < 10K（控制成本，避免上下文爆炸）
- 中英文混合面试支持（技术术语可使用英文，交互以中文为主）
- 知识库引用来源可追溯（每道题标注来源分类：如"计网/HTTP缓存"、"阿里P7面经/行为题"）
- 简历解析准确率 ≥ 90%（关键字段：姓名、技术栈、工作年限、项目名称）
- 单次完整面试时长控制在 20-30 分钟（15-20 道题，含追问）

## 成功标准
- 测试集 30 题技术问答准确率 ≥ 85%（问题与岗位/简历的匹配度）
- 追问相关性 ≥ 80%（追问与前一轮回答存在逻辑关联）
- 评分结果与真人面试官评分偏差 ≤ 1 分（5 分制）
- 真实用户满意度 ≥ 4/5（至少 20 名真实用户试用反馈）
- 部署上线，公网可访问
