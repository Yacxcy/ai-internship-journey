# 美团 — 后端开发工程师 JD

---

## 岗位职责
1. 负责美团核心业务系统（外卖、到店、酒旅等）的后端开发

4. 参与系统性能调优和稳定性保障

## 技术要求
- 精通 **Java**，熟悉 Spring Boot / Spring Cloud 微服务体系

- 熟悉 **Redis**、**Kafka** 等中间件
- 有高并发系统开发和调优经验
- 了解分布式系统理论（CAP、BASE）
