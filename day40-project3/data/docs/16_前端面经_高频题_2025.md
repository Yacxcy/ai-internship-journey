## JavaScript 10题必背

1. **闭包**是什么？使用场景及内存泄漏风险
2. **原型链**：如何实现继承？
3. **Event Loop**：宏任务与微任务的执行顺序
4. **Promise**：手写 Promise.all、Promise.race，理解原理
5. **防抖与节流**：区别及手写实现
6. **深拷贝**：如何处理循环引用？
7. **this 指向**：四种绑定规则及优先级
8. **var / let / const** 的区别
9. `['1','2','3'].map(parseInt)` 结果及原因
10. ES6+ 新特性：可选链 `?.`、空值合并 `??`

## React 8题必背

1. **Fiber 架构**：设计目标与实现原理
2. **Hooks 规则**：为什么不能在条件/循环中调用？
3. `useMemo` 和 `useCallback` 的区别及使用场景
4. `setState` 是同步还是异步？（React 18 自动批处理）
5. **虚拟 DOM** 和 Diff 算法中 `key` 的作用
6. React 事件机制（合成事件）与原生事件的区别
7. `useEffect` 和 `useLayoutEffect` 的区别
8. 受控组件 vs 非受控组件
