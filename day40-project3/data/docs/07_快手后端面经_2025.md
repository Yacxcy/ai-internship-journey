## 一面高频题

### Redis
- 客户端对比（Jedis vs Lettuce vs Redisson）
  - Jedis：同步阻塞，连接不安全
  - Lettuce：异步非阻塞，线程安全，基于Netty
  - Redisson：分布式锁、分布式集合等高级功能

### 限流
- 漏桶 vs 令牌桶算法及使用场景
  - 漏桶：恒定速率处理，适合保护后端服务
  - 令牌桶：允许突发流量，适合API网关

### 消息队列
- 为什么选 RabbitMQ
- Kafka 了解及场景
- 重复消费避免方法（幂等性设计：唯一ID + 状态机）

### 网络
- 粘包/半包概念与解决方案
  - 定长消息
  - 分隔符
  - 消息头+消息体（LengthFieldBased）

### Spring Boot
- 自动配置原理（`@EnableAutoConfiguration` + `spring.factories`）

### MySQL
- 默认隔离级别
- 可重复读能否解决幻读
- 三大日志作用与写入时机（redo log / undo log / binlog）

### 线上排障
- 无日志/无后台数据如何定位问题

### 手撕算法
- 字符串相加（模拟加法）
