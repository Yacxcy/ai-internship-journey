# 产品经理 & 数据分析 面试题（2025校招）

## 数据分析类（核心考点）

### 指标与归因分析

**某电商App次日留存仅30%，竞品55%，怎么分析？**
- 漏斗诊断 → 用户画像对比 → 原因推测（引导不足/价格错位/支付复杂） → 分层优化方案

**用户平均使用时长从2h降到1.5h，怎么排查？**
- 用户行为路径分析 → 内容消费时长占比 → 新老用户分层 → 算法/功能冗余/竞品冲击排查

**付费转化率从5%降到3%，ARPU值持平，怎么分析？**
- 用户分层看高价值付费用户占比 → 新手引导 → 用户疲劳 → 竞品活动

**核心指标断崖式下跌，没有告警，怎么定位？**
- 确认下跌范围 → 数据埋点排查 → 功能变更回查 → 外部环境 → 分层分析
