## IO多路复用

### select / poll / epoll 区别

| 维度 | select | poll | epoll |
|------|--------|------|-------|
| 数据结构 | 位图 | 链表 | 红黑树+就绪链表 |
| 时间复杂度 | O(n) | O(n) | O(1) |
| fd限制 | 1024 | 无 | 无 |
| 触发方式 | LT | LT | LT + ET |
| 内存拷贝 | 每次全量拷贝 | 每次全量拷贝 | mmap共享内存 |

### epoll的ET和LT
- **LT（水平触发）**：只要fd就绪就一直通知，不处理会重复通知
- **ET（边缘触发）**：fd从不可读变为可读时通知一次，必须一次读完

## 零拷贝技术

- 传统IO：磁盘→内核缓冲区→用户缓冲区→Socket缓冲区→网卡（4次拷贝）
- sendfile零拷贝：磁盘→内核缓冲区→Socket缓冲区（DMA拷贝）→网卡（2次拷贝）
- mmap零拷贝：磁盘映射到用户空间，减少一次拷贝
