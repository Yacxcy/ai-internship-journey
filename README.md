## 📦 Projects

### Project 0: AI ChatBot (Day 7)
基于 Streamlit + DeepSeek API 的网页版 AI 助手。

**功能**：
- 流式输出（打字机效果）
- 多轮对话上下文管理
- 4 种角色预设（助手/老师/面试官/翻译）
- 实时 Token 用量统计
- 对话历史导出

**技术栈**：Python, Streamlit, OpenAI SDK, DeepSeek API

**运行**：
\`\`\`bash
uv pip install -r requirements.txt
streamlit run day07-streamlit/app.py
\`\`\`
