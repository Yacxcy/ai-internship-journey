# Project 1: 法律法规咨询

## 项目简介

本项目是一个基于 Dify Advanced Chat 工作流搭建的法律法规咨询助手。应用通过“问题改写 + 混合检索 + Rerank 精排 + 大模型生成”的 RAG 流程，围绕本地法律法规知识库回答用户问题，并在答案末尾标注文档引用来源。

> 说明：本项目用于法律法规知识查询与学习辅助，不构成正式法律意见。涉及具体纠纷、诉讼、合同审查或合规决策时，建议咨询执业律师或主管部门。

## 用户画像

- 普通公众：希望快速了解民法典、宪法、食品安全、网络安全等法律法规条文含义。
- 学生与学习者：需要围绕法律法规进行检索、问答、复习和条文定位。
- 基层工作人员或业务人员：需要在日常工作中快速查询相关法规依据。
- 主要场景：输入口语化法律问题，获得基于知识库的法规解释、条文依据和相关文档来源。
- 核心痛点：法律文本篇幅长、检索成本高、口语问题难以直接匹配条文、答案需要可追溯依据。

## 核心功能

1. 口语问题改写：将用户输入的自然语言法律咨询问题提炼为规范法律检索关键词。
2. 混合检索：基于改写后的关键词，在多个法律法规知识库中结合向量检索与关键词检索召回相关内容。
3. Rerank 精排：使用重排序模型对召回片段进行相关性排序，提高答案依据质量。
4. 法律回答生成：基于检索上下文生成回答，避免脱离知识库自由发挥。
5. 引用来源标注：答案末尾使用 `[文档名]` 标注文档来源，便于用户追溯原文。
6. 边界问题处理：知识库没有覆盖的问题提示超出范围；完全无关问题礼貌拒答。

## 不做的事

- 不替代律师出具正式法律意见、诉讼策略或法律文书结论。
- 不回答与知识库无关的闲聊、娱乐、情感咨询或其他领域问题。
- 不对知识库没有覆盖的法规或事实作确定性判断。
- 不处理图片、语音、文件上传等多模态输入；当前工作流仅面向文本问答。

## Dify 工作流设计

工作流文件：`法律法规咨询.yml`

### 应用配置

- 应用名称：法律法规咨询
- 应用模式：Advanced Chat
- 文件上传：关闭
- 语音转文字：关闭
- 文字转语音：关闭
- 检索资源显示：开启
- 敏感词规避：关闭

### 节点流程

```text
用户输入
  ↓
问题改写LLM
  ↓
知识检索
  ↓
法律回答生成LLM
  ↓
直接回复
```

### 节点说明

| 节点 | 类型 | 作用 |
| --- | --- | --- |
| 用户输入 | Start | 接收用户原始法律咨询问题 |
| 问题改写LLM | LLM | 将口语化问题改写为 20 字以内的法律检索关键词 |
| 知识检索 | Knowledge Retrieval | 在多个法律法规知识库中检索相关片段 |
| 法律回答生成LLM | LLM | 结合检索上下文生成最终法律法规回答 |
| 直接回复 | Answer | 将 LLM 输出直接返回给用户 |

## 技术方案

- 平台：Dify Cloud / Dify
- 应用类型：Advanced Chat 工作流应用
- 核心范式：RAG（Retrieval-Augmented Generation）
- 问题改写模型：`deepseek-v4-flash`
- 回答生成模型：`deepseek-v4-flash`
- 模型供应商：`langgenius/deepseek/deepseek`
- 知识检索模式：多知识库检索（multiple），工作流当前绑定 8 个 `dataset_id`
- 混合检索权重：向量检索 `0.7`，关键词检索 `0.3`
- Embedding 模型：`BAAI/bge-large-en-v1.5`
- Embedding 供应商：`langgenius/siliconflow/siliconflow`
- Rerank 模型：`BAAI/bge-reranker-v2-m3`
- Rerank 供应商：`langgenius/siliconflow/siliconflow`
- 检索参数：`top_k = 10`，`score_threshold = 0.2`
- 回答生成温度：`temperature = 0.7`

## Prompt 约束

### 问题改写

- 提取核心法律概念和术语，用空格分隔。
- 保留用户提到的具体法条编号。
- 保留用户提到的具体法律名称。
- 仅输出一行关键词，不输出解释、说明或标签。
- 关键词控制在 20 个字以内。

### 法律回答生成

- 必须基于知识库上下文回答。
- 知识库没有覆盖的领域问题，提示超出知识库范围并建议查询权威渠道。
- 对完全无关的问题礼貌拒绝。
- 答案末尾必须使用 `[文档名]` 标注引用源。
- 多个引用使用 `[文档1][文档2]` 的格式。

## 使用方法

1. 在 Dify 中创建或进入工作空间。
2. 导入 `法律法规咨询.yml` 工作流文件。
3. 将本项目中的法规 Markdown 文档导入 Dify 知识库。
4. 在工作流的“知识检索”节点中绑定对应知识库。
5. 配置 DeepSeek 与 SiliconFlow 插件或模型供应商凭据。
6. 运行调试，输入法律法规问题进行测试。
7. 发布应用后供用户以聊天方式使用。

## 示例问题

- 民法典对合同违约责任是怎么规定的？
- 宪法中公民有哪些基本权利和义务？
- 食品安全法对食品生产经营者有哪些要求？
- 网络安全法中网络运营者需要履行哪些安全保护义务？
- 环境保护税的纳税人和征税对象是什么？
- 基本医疗卫生与健康促进法对医疗卫生服务体系有什么规定？

## 成功标准

- 领域内问题：至少 10 个知识库范围内问题测试，答案准确率不低于 85%。
- 引用可追溯：答案末尾能够标注文档来源，引用格式符合 `[文档名]` 规范。
- 边界问题：对知识库范围外或无关问题能够拒答或提示超出范围。
- 响应效率：常规文本问答平均响应时间不超过 5 秒。
- 可维护性：新增法规文档后，可通过导入知识库并绑定检索节点扩展覆盖范围。
