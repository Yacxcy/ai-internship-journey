# 字节跳动 - 后端开发 - 三轮技术面经

## 来源
牛客网真实面经汇总（2025-2026）

---

## 字节面试流程与特点

| 轮次 | 时长 | 核心考察 | 特点 |
|------|------|----------|------|
| **一面** | 40-70min | 算法题（1-2道）+ 计算机基础（网络/OS/语言）+ 项目简述 | 淘汰率最高，基础不牢直接挂 |
| **二面** | 60-90min | 项目深挖 + 中间件（Redis/MySQL/Kafka）+ 场景设计 | "剥洋葱式"追问项目细节 |
| **三面** | 60-90min | 系统设计（高并发架构）+ 技术视野 + 职业规划 | 总监/交叉面，有时你以为HR面结果是技术面 |
| **HR面** | 10-20min | 职业规划、文化匹配、抗压能力 | 考察"聪明、乐观、皮实、自省" |

> ⚠️ **字节特色：连轴转**，一面结束原地等二面，有时三轮一天面完。

## 高频算法题（几乎必考）

| 题型 | 高频题目 | 出现频率 |
|------|----------|----------|
| **LRU Cache** | 实现 O(1) 的 get/put | ⭐⭐⭐⭐⭐ |
| **链表** | 反转链表、K个一组翻转、合并K个有序链表 | ⭐⭐⭐⭐⭐ |
| **滑动窗口** | 最长无重复子串（LeetCode 3） | ⭐⭐⭐⭐ |
| **TopK/第K大** | 快排选择 / 小顶堆 | ⭐⭐⭐⭐ |
| **二分/变体** | 旋转排序数组找最小值 | ⭐⭐⭐ |
| **动态规划** | 最长递增子序列、接雨水、跳跃游戏 | ⭐⭐⭐⭐ |
| **二叉树** | 层序遍历（含之字形）、最近公共祖先 | ⭐⭐⭐ |
| **图** | 判断无向图是否为二分图、检测环 | ⭐⭐⭐ |
| **栈** | 有效括号、接雨水（单调栈） | ⭐⭐⭐ |

## 备考建议

| 阶段 | 内容 | 时间 |
|------|------|------|
| 刷题 | LeetCode Hot 100 + 剑指 Offer，每天 2-3 道 | 持续 |
| 项目深挖 | 用 STAR 法则复盘 1-2 个项目，准备数据化成果 | 2-3 周 |
| 系统设计 | 准备 10+ 经典场景设计（秒杀、短链、IM、排行榜） | 2-3 周 |
| 八股文 | 按"原理 + 对比 + 实践踩坑"逻辑回答，不要背书 | 1-2 周 |
| 模拟面试 | 找人 mock，录音回听改进表达 | 1-2 周 |

> **关键提醒**：字节面试官给挂掉最常见的原因是——"基础知识点背得挺熟，但说不清楚为什么这样设计，也没有自己的判断。"

## 2025-2026 年面试新趋势

1. **JDK 21 新特性**：虚拟线程（Virtual Thread）、分代 ZGC、record 类、模式匹配成为新考点
2. **项目追问更深**：不只是问"做了什么"，而是"为什么选这个方案、trade-off 是什么、量化收益是多少"
3. **系统设计更贴近业务**：抖音推荐、秒杀、短链、IM 等字节业务场景频繁出现
4. **AI 大模型后端岗位**：大模型推理服务架构（vLLM/PagedAttention）、分布式训练等新方向出现
