## 高频考点分类

### Go语言
- channel底层结构与收发流程
- defer执行顺序（LIFO）
- 切片扩容机制（<1024翻倍，≥1024约增长25%）
- sync.Map并发安全原理
- GMP调度模型

### 操作系统
- 并发与并行区别
- volatile关键字
- 网络IO与Reactor模式
- 进程宕机数据丢失问题

### Redis
- AOF与RDB区别
- 缓存与本地缓存取舍
- 大容量缓存解决方案

### MySQL
- 分表策略（水平拆分/垂直拆分）
- 事务与隔离级别
- 慢查询排查方法
- 索引回表机制

### TCP/IP
- 三次握手
- 滑动窗口
- Nagle算法
- 延迟确认

### 手撕代码
- 定时器实现
- 两个goroutine交替打印奇偶数
