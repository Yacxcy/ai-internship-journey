## 一面高频题

### 项目相关
- 实习/项目含金量
- 接口幂等性如何保证
- 慢SQL排查（EXPLAIN各字段含义）
- 缓存雪崩/穿透/击穿的区别和解决方案

### Redis
- 为什么快（内存+IO多路复用+简单数据结构）
- 分布式限流（Redisson）
- 限流算法对比（固定窗口/滑动窗口/漏桶/令牌桶）

### MySQL
- B+树 vs B树（为什么MySQL用B+树）
- 默认隔离级别（RR）
- MVCC 与 ReadView 各字段的含义
- 可重复读如何实现
- SQL查询优化实战

### Java
- Bean生命周期

### 手撕算法
- 删除链表倒数第N个结点
- 二分查找
- 合并区间

- 重排链表

## 美团面试特点

1. **重视项目经验**：会花大量时间深挖项目细节
2. **场景题较多**：如限流、幂等性、缓存一致性
3. **算法难度适中**：以LeetCode中等难度为主
4. **AI面试环节**：美团2025年引入了AI初筛面试
5. **横向对比严重**：竞争非常激烈
