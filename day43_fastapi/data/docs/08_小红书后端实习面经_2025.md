# 小红书后端实习面经（2025）

## 来源
CSDN、SegmentFault 真实面经（浙大 SSP 选手分享）

---

## 面试流程
3-4轮技术面 + HR面，周期约3周

---

## 核心考察点

### 实习/项目
- 技术难题与解决方案
- 高并发优化（Arthas/JProfiler定位、索引优化、Redis缓存、线程池调优、异步化）

### 并发编程
- 固定线程池理解/场景/优缺点/拒绝策略
- ThreadLocal 原理与内存泄漏
- volatile 原理（内存屏障）

### Redis
- 5种基础数据结构+高级结构
- RDB/AOF对比
- 过期键删除策略（惰性删除+定期删除）
- 内存淘汰策略（allkeys-lru推荐）
- Redisson 看门狗机制（WatchDog自动续期）

### HashMap
- 非线程安全的原因
- get流程
- 高并发死循环/数据覆盖问题（JDK7头插法导致的环形链表）
- ConcurrentHashMap/Hashtable 区别

### MySQL
- 存储引擎对比（InnoDB vs MyISAM）
- InnoDB B+树索引
- 联合索引最左前缀原则
- 索引优化原则

### JVM
- 堆与栈区别
- 对象生命周期
- GC回收算法
- volatile 底层原理
