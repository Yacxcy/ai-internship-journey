## 高频考点（约7道核心题）

### C++ 语言特性
- 多态 + 内存对齐
- `const` 和 `static` 的使用
- 菱形继承的内存模型与虚拟继承
- `std::move` 与 `std::forward` 区别
  - move：将左值转换为右值引用
  - forward：完美转发，保持参数的值类别
- 写时复制（Copy-on-Write）原理

### 函数式编程
- `function`、`lambda`、`bind` 之间的关系
  - function：可调用对象的包装器
  - lambda：匿名函数对象
  - bind：参数绑定

### 网络编程
- epoll线程安全分析
  - epoll实例本身是线程安全的
  - 但事件处理需要注意并发
